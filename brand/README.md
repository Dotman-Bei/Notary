# Notary logo

**The mark:** a notary's crimped seal, split in two by an N cut through its rim. The halves interlock, so
they read as one seal: one half for what was sealed, the other for what was revealed.

**The wordmark** is drawn for Notary, not set in a font, and its N repeats the cut in the mark. Every file
is outlined vector paths, so no font needs to be installed.

## Files

| Use | Files |
| --- | --- |
| Logo with name (default) | `notary-lockup-color.svg`, `-black`, `-white`, `-on-olive` |
| Mark alone, 48px and up | `notary-mark-color.svg`, `-olive`, `-black`, `-white` |
| Favicon and anything under 48px | `notary-favicon.svg` (switches colour for dark browser themes), `-olive`, `-white` |
| Name alone | `notary-wordmark-olive.svg`, `-black`, `-white` |

## Colour

| Name | Hex | Role |
| --- | --- | --- |
| Olive | `#38450f` | Primary ink, left half |
| Moss | `#7c9128` | Right half, colour mark on light grounds |
| Light moss | `#a9bd4e` | Right half, on olive only |
| Bone | `#ecebe7` | Ground, or ink on olive |

Use black or white only where colour isn't available.

## Rules

- Keep clear space of at least one quarter of the mark's width on every side.
- Don't use the lockup below 24px tall. Below that, use the favicon mark alone.
- Don't rotate, outline, stretch, add effects to, or recolour the halves.
